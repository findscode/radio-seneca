# Журнал изменений

## 0.5.4

- ASCII-фон двигается плавно: знак сдвигается в соседнюю клетку за 1,1 секунды, новый знак проявляется.
- Начальный узор случайный при каждой загрузке. Узор больше не совпадает у всех слушателей в один час.

## 0.5.3

- Символы ASCII-фона: `x`, `+`, `o`, `~`. Цвет темнее и ближе к фону.
- Начальная раскладка случайная. Каждый знак двигается в свою сторону.
- Ни один символ не занимает поле целиком: у каждого есть предел доли.

## 0.5.1

- Обложка стала фоном: размытое изображение с затемнением и небольшая обложка по центру. Без обложки остаётся заглушка.
- ASCII-фон меняется по правилам Game of Life.
- Метка `NOW` не переводится ни на русский, ни на английский.
- Клиент открывается по адресу `https://seneca.by`.

## 0.5.0

- Радиосервер и клиент открываются по HTTPS. Поток и WebSocket тоже идут по защищённому соединению.
- Плейлист на радиосервере уже играет случайно, без повтора, затем начинает новый круг.
- Публичный `nowplaying` не содержит слушателей за 24 часа. Строка `24H` остаётся скрытой.

## 0.4.0

- Русский и английский. Язык по умолчанию — язык браузера. Выбор хранится в `localStorage`.
- Цитата одна на всех и считается по часу UTC. ASCII-узор сдвигается по тому же часу.
- При обрыве потока вместо названия стоит «Эфир недоступен», рядом «Переподключение…». Повтор идёт с паузой 1, 2, 4, 8, 16 и 30 секунд.
- В консоль пишутся только ошибка и переподключение.

## 0.3.0

- Экран берёт текущий трек, обложку, историю и число слушателей из радиосервера.
- Обновление идёт по WebSocket. Если сокет недоступен, клиент опрашивает `nowplaying` каждые 15 секунд.
- Строка `24H` скрыта, пока в данных нет этого числа.
- ASCII-узор заполняет всю правую панель.

## 0.2.0

- Play и Pause запускают поток из `VITE_STREAM_URL`.
- Громкость и Mute сохраняются в `localStorage`.
- После загрузки страницы звук не стартует сам.

## 0.1.0

- Каркас клиента на React и Vite.
- Один экран для десктопа и мобильного веба.
- Фикстура вместо радиосервера. Звука нет.
