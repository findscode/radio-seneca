# Брендинг Seneca

## Название

- Продукт — Seneca.
- Радиосервер — AzuraCast.
- Эфир — то, что слушает человек.

## Логотип

- Слово `SENECA` латиницей.
- Шрифт: Caesar Dressing.
- Это единственное исключение из правила «весь текст в IBM Plex Mono».
- Размер на десктопе: 28 px. На мобильном: 22 px. Проверить читаемость.
- Цвет логотипа: открыто. Рекомендация — `#F2EFE8`.

## Иконка приложения

- Белая точка на чёрном фоне `#0E0E0E`, без букв.
- Точка повторяет индикатор LIVE в интерфейсе.

## Характер

- Монохром. Минимум цвета.
- CLI-детали: префиксы вроде `> RECENT`, текст в верхнем регистре, моноширинный шрифт.
- Арт создаёт ASCII-фон под основной частью экрана, под углом 45°.

## Цвета

| Роль | Цвет |
|---|---|
| Фон | `#0E0E0E` |
| Текст | `#F2EFE8` |
| Акцент | `#FFFFFF` |
| Вторичный текст | `#8A8A8A` |
| Трек громкости | `#404040` |
| Разделители | `#333333` |
| Обложка (заглушка) | `#1E1E1E` |
| Фон истории | `#262626` |
| ASCII-узор | `#292929` |

## Шрифты

- IBM Plex Mono — для всего текста.
- Caesar Dressing — только для логотипа.
- Anton и Inter не используем.

## Фирменные элементы

- Белая точка рядом с LIVE.
- Белая кнопка Mute.
- Разделители 2 px.
- ASCII-узор под основной частью экрана.
- Цитата Сенеки под обложкой, меняется раз в час.

## Чего избегаем

- Яркие цвета и градиенты.
- Декоративные иконки.
