# Архитектура клиента

## Общая схема

- Клиент — статический сайт. Собирается в файлы, которые раздаёт любой хостинг.
- Своего бэкенда у Seneca нет. Серверная часть — радиосервер (AzuraCast).
- Клиент получает от радиосервера поток, данные «Сейчас в эфире» и обложки.

## Стек

- React и Vite.
- Сборка в статические файлы.

## Звук

- Элемент `audio` играет поток Icecast.
- Play, Pause, громкость и Mute управляют элементом `audio`.
- Автозапуска нет. Звук стартует только после нажатия Play.

## Сейчас в эфире

- Клиент получает данные по WebSocket от AzuraCast.
- Резерв: если WebSocket недоступен, клиент опрашивает `nowplaying` каждые 15 секунд.
- Обложка берётся из данных трека. Если URL нет, показываем заглушку.

## ASCII-фон

- Фон состоит из четырёх знаков: `x`, `+`, `o`, `~`. Знаки тёмно-серые, близкие к фону.
- Расположение задаётся случайно при каждой загрузке страницы. Слушатели видят разные рисунки.
- Знаки двигаются по своим правилам. Каждый знак сдвигается в свою сторону.
- Новый знак появляется в пустой клетке при двух одинаковых соседях. Лишние соседи гасят знак.
- Баланс: ни один знак не занимает больше 40% живых клеток. Каждый знак остаётся не меньше 12%.
- Переход между шагами плавный: около 1,1 секунды. Знак сдвигается в соседнюю клетку, новый знак проявляется.
- При `prefers-reduced-motion` узор статичен.

## Цитата

- Выбирается по текущему часу UTC.
- Все слушатели видят одну и ту же фразу.

## Сбои и переподключение

- При ошибке `audio` клиент показывает строку «Эфир недоступен».
- Рядом показывается статус «Переподключение…».
- Клиент повторяет подключение с растущей паузой. Максимум 30 секунд.

## Настройки в браузере

- Громкость, Mute и язык хранятся в `localStorage`.
- Язык по умолчанию — язык браузера. Русский для `ru`, иначе английский.

## Решения

- Публичный WebSocket `wss://radio.seneca.by/api/live/nowplaying/websocket` отдаёт `nowplaying` без входа. Канал — `station:seneca`.
- В публичном `nowplaying` есть `listeners.current`. Числа за 24 часа нет. `listeners.unique` — это не `24H`. Строку не показываем.
- Плейлист на радиосервере идёт в случайном порядке, без повтора, затем начинается новый круг.
