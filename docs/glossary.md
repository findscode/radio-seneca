# Глоссарий

Один термин — одно понятие. В текстах и интерфейсе используем русские названия. Колонка «В коде» — рабочее имя для кода и API. Она пока на согласовании.

| Термин | Значение | В коде |
|---|---|---|
| Seneca | Название продукта | — |
| Радиосервер | AzuraCast: плейлист, поток, метаданные | — |
| Эфир | То, что слушает человек | `broadcast` |
| Поток | Адрес Icecast для звука | `stream` |
| Трек | Один аудиофайл из плейлиста | `track` |
| Плейлист | Порядок треков, ведёт радиосервер | `playlist` |
| Сейчас в эфире | Текущий трек и его данные | `nowplaying` |
| История | Последние 5 треков | `history` |
| Обложка | Картинка трека, без неё заглушка | `cover` |
| Цитата | Фраза Сенеки, меняется раз в час | `quote` |
| Слушатель | Посетитель клиента, без аккаунта | `listener` |
| Клиент | Веб-приложение Seneca | — |

## Правила

- Слово «станция» в технических текстах не используем. Продукт — Seneca.
- Блок в интерфейсе называется «Сейчас в эфире». В коде — `nowplaying`.
