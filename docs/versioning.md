# Версионирование

Seneca использует [семантическое версионирование](https://semver.org/lang/ru/): `MAJOR.MINOR.PATCH`.

## Правила

- **MAJOR.** Ломающие изменения. Например, новый формат данных от радиосервера или новый ключ в `localStorage`, который теряет старые настройки.
- **MINOR.** Новая функция без поломки старой. Например, третий язык интерфейса.
- **PATCH.** Исправление ошибки без новых функций.

## Стартовая версия

- До публичного запуска используем `0.x.x`. В этом диапазоне API и поведение могут меняться.
- Версия `1.0.0` — первый релиз для слушателей.

## Теги и журнал

- Каждый релиз получает git-тег `vX.Y.Z`.
- Изменения записываем в `CHANGELOG.md`.
- Пре-релизы помечаем суффиксом, например `v1.0.0-rc.1`.
